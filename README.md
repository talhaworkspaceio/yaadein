# FrameStudio — Photo Frame Customizer

A Next.js photo frame customizer with real-time preview.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Features
- 6 portrait frame styles (Oak, Matte Black, Gold, White, Silver, Walnut)
- Rotate controls (±45°, ±90°, fine slider)
- Upload your own photo or choose from samples
- Fully responsive — mobile sidebar drawer
